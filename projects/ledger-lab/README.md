# Project: Ledger Lab

## What this project is

Ledger Lab is the reference implementation of the Sharealedger open accounting
framework. This project defines what Ledger Lab should build — the requirements,
conformance fixtures, and acceptance criteria. The implementation lives in the
separate `ledger-lab` repository.

## Goal

Produce a running, testable implementation of the open accounting framework that
demonstrates the core shared ledger concepts and serves as the reference for
conformance testing.
